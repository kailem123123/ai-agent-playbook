# Проверка кандидата к публикации

Дата: 22 октября 2026 года.

## Выполнено

- Руководство переработано для общего применения; пример — локальный импорт задач.
- Удалены ссылки на личное хранилище, внутренние пути и предметные рабочие примеры.
- Публичный комплект состоит только из текстов, шаблонов и проверочного скрипта.
- Ссылки на официальные страницы Git и GitHub открыты при подготовке.
- Лицензия MIT и сведения об использовании ИИ включены.

## Воспроизводимая проверка

В корне репозитория: `python scripts/check_docs.py`.

Перед публикацией отдельно проверяются полный список файлов и Git-история.
Поиск известных названий, адресов и форматов секретов дополняется чтением текста.
Отсутствие совпадений не является математической гарантией отсутствия секретов.

## Ограничения

Независимое внешнее ревью не выполнялось. Учебное приложение не реализовано,
поэтому сценарии из примера являются планом, а не отчётом о пройденных тестах.
Отображение Markdown непосредственно на GitHub проверяется после публикации.
Доступность внешних ссылок и возможности инструментов со временем могут измениться.
